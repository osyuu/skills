# .out-of-scope

否決過的路，一篇一條，附理由與觸發重審的條件。

**只記結論會讓人再走一遍。** 這些決定多半是量過、試過、或踩過之後才收掉的，
而下一個 session（或下一個人）看到的只有「現在沒有這個東西」——那跟「還沒做」
長得一模一樣，於是同一條路會被重新提案、重新實作、重新否決。

每篇的形狀：

- 標題一句話講清楚**否決的是什麼**（不是「為什麼」）。
- `## 為什麼不做` —— 理由要帶得走：量到的數字、衝突的機制、成本落在誰身上。
- `## 觸發重審的條件` —— 什麼情況下這個決定應該被推翻。沒有就寫「無」。
- `## 先前的提議` —— 誰在什麼時候提過，含當時的脈絡。

格式沿用 mattpocock 的 `.out-of-scope/`（`Why this is out of scope` + `Prior requests`）。
